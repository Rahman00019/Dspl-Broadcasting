# DSPL BROADCASTING Website

This folder is ready for GitHub Pages.

Files:
- index.html — complete website
- assets/dspl-logo.png — transparent DSPL logo made from the supplied white-background image
- assets/dspl-background.jpg — supplied black-background image used as the website visual background

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and the `assets` folder.
3. Open Settings → Pages.
4. Under Build and deployment, choose `Deploy from a branch`.
5. Select the `main` branch and `/ (root)`, then Save.
6. GitHub will give you the website address.
